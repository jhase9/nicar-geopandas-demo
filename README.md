# nicar-geopandas-demo

A lesson on how to analyze geospatial data in Python, with a focus on San Francisco data.

To start, open your Terminal and run:

```
source .venv/bin/activate

jupyter lab
```

## Additional helpful resources (no Python needed):

### [Datawrapper](https://www.datawrapper.de/)

Great for visualizations

### [Mapshaper](https://mapshaper.org/)

Can help easily clean, merge, and simplify geospatial data.

### [QGIS](https://qgis.org/)

A GUI (user interface / app) to do lots of things with maps.

### [Geocodio](https://www.geocod.io/) and [BatchGeo](https://batchgeo.com/)

Helpful for turning addresses into latitude/longitude coordinates

### [Geojson.io](https://geojson.io/)

Easy way to create and explore geojson data

### [Census TIGER/Line files](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html)

Get outlines of census tracts, states, ZIP code tabulation areas, etc.

### [overpass turbo](https://overpass-turbo.eu/) and [Overture](https://overturemaps.org/)

Query data for points of interest (cities, restaurants, etc.)

### [epsg.io](https://epsg.io/)

Explore and compare coordinate reference systems to find the right one.
